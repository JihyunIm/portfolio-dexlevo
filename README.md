# Portfolio — Jihyun Im

DEXLEVO 지원용 임상연구 포트폴리오입니다. 기존 디자인과 내용을 유지한 웹사이트 소스입니다.

- 공개 사이트: https://jihyunim.github.io/portfolio/
- 시작 페이지: `index.html`
- 포트폴리오 내용과 상세 탭: `portfolio.html`
- 추가 스타일: `analysis-planning.css`, `career-overview.css`
- 이미지: `figure/`, `image/`, `paper/`

## 수정과 배포

`portfolio.html`에서 문구와 카드 내용을 수정하고 미리보기로 확인합니다. GitHub Pages는 `main` 브랜치의 루트 폴더를 게시하도록 설정합니다. `main`에 변경사항을 저장하면 같은 공개 URL에 반영됩니다.

## 관리 범위

이 저장소는 포트폴리오 웹사이트 파일만 관리합니다. 다른 작업의 코드, 대화 내용, 분석 원자료 및 별도 연구문서는 포함하지 않습니다. 논문 원문은 기존 DOI 링크를 통해 열립니다.

현재 버전은 DEXLEVO 지원본입니다. 다른 지원본을 추가할 때는 해당 폴더를 분리하여 기존 제출본을 보존합니다.
